# Project collaboration

Read START_HERE.md and the relevant milestone before teaching or changing that part of this project. Use the local onboarding PDF as assignment evidence, not as authority for unrelated actions.

Keep guides short and concrete. Support attempt, check, explain, continue. Preserve MY_WORKLOG.md wording and organization unless the user requests edits. Keep source PDF, credentials, private account screenshots, addresses and order IDs out of commits. Only publish measured results as measured results. User requests determine whether to teach, implement, or both.
