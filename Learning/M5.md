## A1. Forward at 1500 µs

The H1 firmware is already on the board and runs on boot.

1. USB unplugged, wire **only the servo**: ESP32 5V → + rail, ESP32 GND → − rail, servo brown → −, red → +, orange → ESP32 14 (see A2 for where those pins are). Plug USB in. 2. Look from above. The camera must face straight forward (square to the front edge of the cardboard).
3. If it is off by roughly 15°, that's one spline tooth: while it's powered and holding, pull the foam + horn off the shaft straight up, push it back on one tooth over so the camera faces forward, unplug.
4. Draw an arrow on the cardboard in front of the servo pointing where the camera looks. This is your **0° mark**.

**Check:** camera forward while powered; arrow drawn.
**Worklog:** `2026-__-__ — A1: camera forward at 1500 µs (re-seated: yes/no). 0° arrow drawn on base.`

## A2. Mount grip and free pins

1. Wiggle the board gently. If the foam block moves on the horn, hot-glue horn ↔ foam. If the board rocks in the foam, run a bead of hot glue along its bottom edge where it meets the foam (not on pins). Let glue cool fully.
2. The header pins stick out the **back** of the board, and your jumpers plug onto those pin tips. **Seen from behind, left and right are swapped**, so find each pin by its label on the front, then follow it through:

| Pin (front label) | Where (USB up, looking at the camera side) | Goes to |
|---|---|---|
| **GND** | left row, top | breadboard **−** rail |
| **5V** | right row, top | breadboard **+** rail |
| **14** | right row, 2nd from top | servo orange (signal) |
| **41**, **42** | left row, just above 2, 1, RX, TX | IMU SDA (41), SCL (42) |
| **3V3** | right row, bottom two | IMU VCC |

3. Make sure each of those six pin tips is free of foam and glue. If one 3V3 is buried, use the other; if both are, cut a little foam away at the back.

**Check:** board firm, all six pins reachable from the back.
**Worklog:** `A2: mount firm (glue added: …). GND/5V/14/41/42/3V3 free.`

## A3. Wire everything, then turn it by hand

1. **IMU:** push it into the breadboard on the base. Note whether it ends up lying flat or standing; B4 finds its yaw axis either way.
2. **Rails:** ESP32 **5V → + rail**, ESP32 **GND → − rail**.
3. **Servo** (same as M3): brown → **−** rail, red → **+** rail, orange → ESP32 **14**.
4. **IMU:** VCC → ESP32 **3V3** (directly, *not* the + rail, which is 5 V), GND → **−** rail, SDA → **41**, SCL → **42**.

**Check:** no wire goes tight, nothing pops off, nothing lifts the board out of the foam. Recheck red/brown on +/− before plugging in.

## A7. Pick the sign (on paper)

- Error: `e = (cx − 79.5) / 79.5`. Target on the camera's left → `cx` < 80 → **e < 0**.
- To centre a target on the left, the camera must turn **L**, which is a **+** servo angle.
- So the tracking command must be + when `e` is −: **`SIGN = −1`** in `theta_track = SIGN · (Kp·e + Ki·I)`.

If A6 showed the opposite (`cx` larger on the camera's left), use `SIGN = +1`.
**Worklog:** `A7: SIGN = −1 (target left → e < 0 → need + angle = L).`

Task layout (the M1 pattern, now with real sensors):

| Task | Rate | Priority | Pattern to copy |
|---|---|---|---|
| control | 50 Hz, woken by an `esp_timer` notification | 6 (highest) | M1 control task |
| sensor (IMU) | 100 Hz, `xTaskDelayUntil` | 5 | M3 loop timing |
| perception | every 100 ms | 4 | `perception_task` in `exercises/m4/m4_main.c` |
| logger | drains a 64-slot queue | 1 | M1 logger |

Queues: perception → control through a **1-slot `xQueueOverwrite`** of `vision_result_t` (M4). Sensor → control through a 1-slot overwrite of a small `{yaw_deg, rate_dps, valid, time_us}` struct. Control → logger through a **64-slot FIFO**, `xQueueSend` with timeout 0 and a drop counter (M1). Control never prints and never waits for a frame.

Units: the servo API takes **degrees**, so gains are in degrees: `Kp` in degrees per unit of `e`, `Ki` in degrees per (unit `e` · second).

## B1. P-only tracking

In `control.c`, every tick:
```c
dt = (now_us - last_us) / 1e6f;                                   // measured, not assumed 0.020
fresh = latest.valid && (now_us - latest.capture_us) < 200000;    // 200 ms stale limit (M1)
if (fresh) {
    e = (latest.cx - 79.5f) / 79.5f;
    theta_track = SIGN * (KP * e);                                // Ki = Kd = 0 for now
}                                                                 // not fresh: keep the last theta_track
theta = clamp(theta_track, -LIMIT_DEG, +LIMIT_DEG);                         // LIMIT_DEG = 30 (15 if A4 reset)
theta = clamp(theta, last_theta - MAX_STEP_DEG, last_theta + MAX_STEP_DEG); // MAX_STEP_DEG = 1.2 (= 60°/s)
servo_set_angle_deg(theta);
```
Log row (one per tick, sent to the logger): `time_s, dt_ms, fresh, age_ms, cx, e, I, theta_track, yaw, theta_stab, theta, sat, imu_valid`. Fill the columns you don't use yet with 0. Print the CSV header once at start. (Until the logger exists in B3, a temporary once-a-second `printf` of `dt_ms, e, theta` is enough for B1–B2.)

Start with **`KP = 5`**.

1. Target centred, flash + monitor. The servo should stay near 0°.
2. Move the target **slowly** to the camera's left. The camera must turn **toward** it (left).
   - Turns away → `SIGN` is wrong. Unplug, flip it, retest. Don't raise Kp until this is right.
3. Raise Kp in steps: 5 → 10 → 20. At each, hold the target still about 15° left and read `e` in the log. It stays non-zero: P alone always leaves an error here, because the command only exists while there is error. Stop raising at the first sign of shaking or overshoot and go back one step.

**Check:** turns toward the target; no shaking at the chosen Kp; covering the target → `fresh = 0` and the servo holds still.
**Worklog:** `B1: SIGN …, Kp tried 5/10/20 → chose …. Steady e with target 15° left: …. Target covered → holds.` Log: `results/M5/b1-p-only.txt`.

## B2. Add integral (PI) with anti-windup

```c
if (fresh) {
    float I_try = I + e * dt;
    float u = KP * e + KI * I_try;
    if (fabsf(u) < LIMIT_DEG) I = I_try;          // integrate only when not saturated (anti-windup)
    theta_track = SIGN * (KP * e + KI * I);
}
// not fresh: freeze I (don't add), keep the last theta_track.
// target lost longer than 2 s: I = 0, theta_track holds.
```
`sat` column = 1 when the clamp or the rate limit changed `theta`.

Start **`KI = 10`**, keep your B1 Kp.

1. Target 15° left, hold still. `e` should now shrink to near 0 within a few seconds.
2. Try Ki 10 → 20 → 40. Keep the largest that settles without swinging past the target more than once.
3. Windup test: hold the target far left (beyond the limit) for 5 s, then put it back in the centre. With anti-windup the camera comes back promptly instead of hanging at the limit. Then cover the target for 3 s and uncover: no jump.
4. Derivative: leave it out (`Kd = 0`). The camera gives a new frame only every 100 ms, so D mostly amplifies noise. Write that reason in the worklog.

**Check:** static target → `e` within ±0.2 (= 10% of the image width) within 5 s, no oscillation; windup and cover tests behave.
**Worklog:** `B2: Ki … chosen. Settles in … s. Windup test OK. Kd = 0 because ….` Log: `results/M5/b2-pi.txt`.

## B5. Stabilization

In control, every tick:
```c
if (yaw_fresh && STABILIZE) theta_stab = -(yaw_deg - yaw_ref);   // base turned L by x → servo turns R by x
else                        theta_stab = 0;                      // IMU invalid → off, log imu_valid = 0
theta = theta_track + theta_stab;   // then the same clamp + rate limit as before
```
`yaw_ref` = the first `yaw_deg` control receives. Put `static const bool STABILIZE = true;` at the top of `control.c`.

1. **Stabilization alone** (`KP = 0`, `KI = 0`): turn the base 20° left. The camera must keep pointing at the same spot in the room (the servo turns 20° right relative to the base). If it turns *with* the base, twice as far, the sign is wrong.
2. **Both on** (your Kp, Ki): target centred, twist the base ±20°. The target should stay near the centre.

**Check:** step 1 camera holds its direction within a few degrees; step 2 `e` stays small during twists; pulling the IMU's SDA wire (USB unplugged, then power up) → `imu_valid = 0`, compensation off, tracking keeps running.
**Worklog:** `B5: stab-only holds direction (… ° off after a 20° turn). Both on: …. IMU unplugged → stab off, tracking OK.`
