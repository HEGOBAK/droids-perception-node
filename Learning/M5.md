# M5 — PID tracking and single-axis stabilization

[Start here](../START_HERE.md) · [Previous: M4](M4.md) · [Next: M6](M6.md)

**Goal:** center the target with a fixed-rate controller and compensate for base rotation about the controlled axis.

Start with the [task design](../docs/ARCHITECTURE.md). Fix the servo's physical axis, sign and neutral before tuning. If the axis is yaw, its IMU compensation is short-term relative heading; a pitch axis offers gravity-referenced tilt. Document which you choose and what remains uncontrolled.

## Controller exercise

At width W define normalized image error `e=(cx-(W-1)/2)/((W-1)/2)`. It is dimensionless and approximately ±1 at the edges. Choose servo direction so a small positive correction reduces positive error.

Use an explicit position-command design: `u_pid=Kp*e + Ki*I + Kd*D`, `I += e*dt`, `D=(e-e_prev)/dt`. Gains convert normalized error into radians (and account for seconds in I/D). Command `theta = neutral + sign*u_pid + theta_stabilize`, then clamp to calibrated position and rate limits. This design can have steady error with P only; I helps remove it. Do not also integrate the whole PID output as a velocity unless deliberately redesigning gain units and dynamics.

1. Start `Ki=Kd=0` and small Kp. Move the target slowly. Check the sign before increasing gain.
2. Add integral only as needed, with anti-windup when saturated and reset/freeze on target loss. Add a filtered derivative only if it improves measured behavior; repeated old frames do not supply new visual information.
3. Run control at 50 Hz with notification timing, actual `dt`, and bounded work. Keep the last fresh observation; do not wait for a camera frame.
4. For small rotations around the same calibrated axis, compensate with the opposite base-angle change relative to the reference. Verify sign physically. This approximation is not arbitrary 3D stabilization.
5. When the target is stale beyond the chosen threshold, freeze integral and use a documented safe behavior such as holding the last bounded command. For invalid orientation, disable compensation and report the state.
6. Compare compensation on/off under matched target placement and base disturbance. Repeat at least three trials each. Do not change PID gains between the paired comparison.

## Finish when

- Tracking is bounded, target loss is handled, and timing remains measured under camera load.
- Save image error, attitude, command, timestamps and validity. Report RMS error, saturation time, settling behavior and control jitter.
- Initial learning target: a static target stays within 10% of image width from center for 10 seconds without saturation; report actual performance if unmet.

## Explain

How is this feedback controller different from Adam training a neural policy? Why can integral wind up at a limit? Why can one servo not cancel three independent rotations?

**Evidence:** gain table, plots and paired-trial results. Servo command remains an estimate of physical pose without shaft feedback.
