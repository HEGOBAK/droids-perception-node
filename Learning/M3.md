# M3 — Distance and servo independently

[Start here](../START_HERE.md) · [Previous: M2](M2.md) · [Next: M4](M4.md)

**Goal:** obtain valid range measurements and command safe servo movement before closing a feedback loop.

## Distance exercise

Verify your actual HC-SR04P supply, trigger requirements, echo level and measurement interval. The order listing is not a complete datasheet. Use a safe signal interface from [HARDWARE.md](../docs/HARDWARE.md).

1. Generate the specified trigger pulse and measure echo high time using RMT or a hardware timer/capture method. Check [RMT documentation](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/rmt.html).
2. Set a finite acquisition timeout and schedule measurements slowly enough for the module. On missing echo return invalid, never zero meters.
3. Calculate `distance_m = sound_speed_m_s * echo_seconds / 2`. For an illustrative 20°C approximation, 343 m/s and 2 ms yield 0.343 m. Temperature and target geometry affect accuracy.
4. Compare against a ruler at 0.20, 0.50 and 1.00 m where your module and target allow. Collect 30 readings per distance; record bias, spread, failures and target surface.

## Servo exercise

Confirm external power and common signal ground before connection. Start unloaded; do not force the shaft manually while powered or drive into a mechanical stop.

1. Read [MCPWM](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/mcpwm.html). Create timer, operator, comparator and generator objects according to the installed API.
2. Use the servo's documented frame rate and pulse range. A common starting frame is 20 ms, but verify the actual servo. Do not assume every SG90 accepts 500–2500 µs or reaches a true 180°.
3. Start at the specified neutral pulse; try only small offsets. At a 1 MHz timer resolution, each tick is 1 µs. An example 1500 µs pulse in a 20000 µs frame is 7.5% duty.
4. Calibrate a conservative usable angle/pulse interval with an angle reference. Limit both command range and rate. Save direction, neutral, limits, supply and load.
5. Test range while the servo moves. Look for resets, range outliers and power sag before blaming software.

## Finish when

- Range measurements include timeout/validity and measured errors at known distances.
- Servo commands are bounded and cause small predictable movements without resets or end-stop contact.
- You can account for each supply and every used pin.

## Explain

Why divide echo time by two? Why does commanding 30° not prove the shaft physically reached 30°? Why can a servo destabilize the board even when the GPIO signal is correct?

**Evidence:** range CSV, calibration table, short movement recording and power checks.
