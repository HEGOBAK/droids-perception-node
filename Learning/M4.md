# M4 — Camera and colored-object detection

[Start here](../START_HERE.md) · [Previous: M3](M3.md) · [Next: M5](M5.md)

**Goal:** produce a timestamped centroid and validity decision from actual frames.

Read [Espressif's camera component](https://github.com/espressif/esp32-camera) and your matching Freenove pin map. Confirm sensor model and memory configuration. Add the camera component using ESP-IDF Component Manager, select a release compatible with your installed IDF, and commit the manifest and generated dependency lockfile once a build works. Do not assume a version combination is tested before building it.

## Assignment

1. Acquire one frame with the board alone, return the frame buffer after use, and verify image orientation. Begin at a small resolution such as 160×120.
2. Record pixel format and stride. A 160×120 RGB888 image has 57600 pixel bytes; RGB565 has 38400. A JPEG byte stream is compressed data, not an array of RGB pixels: decode before color thresholding or choose a supported raw capture path.
3. Threshold a controlled colored target using a documented color space. If using HSV, record the hue range convention; red can wrap around the hue boundary.
4. Build a binary mask. For selected pixels, `cx=sum(x)/N`, `cy=sum(y)/N`; zero selected pixels means invalid. For points `(10,20),(20,20),(30,20)`, the centroid is `(20,20)`.
5. Reject small/noisy detections and ambiguous multiple objects. Define confidence explicitly, for example blob area fraction plus a minimum area condition; it is not automatically a calibrated probability.
6. Draw/save one frame with mask and centroid for debugging. Send a small value message through the queue, not a borrowed framebuffer pointer. Include acquisition time.
7. Test left, center, right, absent target, similar background and changed lighting. Measure processing time, frame drops and heap over five minutes.

## Finish when

- Centroid direction matches the physical scene and absent targets are invalid.
- Buffer ownership is correct and memory does not leak over the trial.
- You can show failure cases, including lighting and confusing backgrounds.

## Explain

What does image shape `(120,160,3)` mean? Why does JPEG size not equal width×height×channels? Why can averaging all matching pixels put the centroid between two separate objects?

**Evidence:** annotated frames, threshold settings and timing table. Keep large frame captures local.
